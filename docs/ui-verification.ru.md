# Проверка интерфейса — 22 октября 2026

Проверка проведена локально на отдельной SQLite-базе с синтетическими компаниями Acme QA Services и Second QA Business. Рабочая база не использовалась для тестовых записей. `.env` не открывался; тесты и QA-сервер явно отключают загрузку dotenv. Платные модели и SMTP в QA отключены. Публикации и push не выполнялись.

## Результаты

- **84 серверных теста прошли**, включая интеграции с настоящими PostgreSQL 17 / pgvector и Qdrant 1.19.0. Использованы отдельная тестовая SQL-база и тестовые коллекции Qdrant.
- **16 регрессионных тестов интерфейса прошли**. Они исполняют настоящие модули приложения в JSDOM и управляют задержками/ошибками API. Это DOM-тесты; реальные размеры и прокрутка дополнительно проверены в браузере.
- JavaScript проходит синтаксическую проверку и Prettier. Browser demo пересобран с теми же исправлениями.
- В браузере проверены экраны 1280×720 и 390×844, создание запроса, фильтрация, поиск, переключение компаний, модальная форма, публичная заявка и её появление в очереди.
- У страницы Settings восстановилась позиция **720 px** после перехода в Knowledge base и обратно. При переходе в AI usage боковое меню сохранило положение около **200 px** вместо возврата к нулю.
- На мобильном экране ширина страницы равна доступной ширине **375 px** при viewport 390 px с системной полосой прокрутки. Кнопка выхода находится в пределах **x=21…51** внутри панели **x=0…72**.
- В консоли проверенных тестовых вкладок нет ошибок и предупреждений.

## Повторение

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run check:format
python -m pytest
```

Для интеграций установите `TEST_DATABASE_URL` на отдельную тестовую PostgreSQL-базу и `TEST_QDRANT_URL` на доступный Qdrant. Без них соответствующие интеграционные тесты пропускаются. Обычные тесты не читают операторский `.env` и не вызывают реальные модели. Не используйте рабочую SQL-базу в качестве тестовой.

Скриншоты текущей локальной проверки сохранены в `var/qa/ui-workspace-scroll.png`, `var/qa/ui-search-selection.png`, `var/qa/ui-mobile-navigation.png` и `var/qa/ui-public-form-receipt.png`. Каталог `var/` не включается в Git.

Эта проверка не подтверждает работу ещё не активированного OVH-сервера. Реальные OpenAI, SMTP и Turnstile во время этой QA-сессии не вызывались; их интеграционные контракты проверены заглушками.
